# Excel Data Automation

A collection of VBA utilities I created to automate repetitive Excel and file-processing tasks.

These scripts were developed for practical data operations where large numbers of files needed to be modified, combined, renamed, or prepared using Excel.

## What these scripts do

### Modify Column in Files
Updates a specific range across multiple Excel files based on information contained in the filename.

### Combine Data
Combines data from multiple Excel files into a standard template.

### Copy Sheets to Template
Copies worksheets and their formatting from multiple workbooks into a common template.

### Rename Files
Renames files automatically by matching the existing filename against a reference list in Excel.

## Why I built these

These were practical automation tools used to reduce repetitive manual work when processing large numbers of files.

The scripts are older examples of my automation work. I am also building newer Python-based projects focused on data quality, analysis, and AI data operations.
